# Reproduction Simulator

An educational game designed to teach students about different forms of reproduction through interactive simulations.

## Overview

The Reproduction Simulator is an interactive learning tool built with Godot 4.4 that helps students understand various biological reproduction processes, including:

- Binary Fission (single-celled organisms)
- Mitosis (asexual reproduction in multicellular organisms)
- Sexual Reproduction (amphibians, birds, mammals)

The simulation features multiple reading levels to accommodate different age groups (6-7, 8-10, 11+).

## Features

- **Multiple Learning Modes**:
  - **Explore Mode**: Free exploration of reproduction types
  - **Guided Learning**: Step-by-step tutorials
  - **Compare & Contrast**: Compare different reproduction methods
  - **Quiz Mode**: Test knowledge with interactive quizzes

- **Adaptive Content**: Three reading levels with age-appropriate vocabulary and explanations
- **Interactive Simulations**: Visual representations of cellular processes
- **Progress Tracking**: Track learning progress across modules
- **Accessibility Options**: High contrast mode, subtitles, and audio settings

## Installation

1. Download and install [Godot 4.4](https://godotengine.org/download)
2. Clone this repository
3. Open the project in Godot
4. Run the project (F5)

## Development

This project is structured to allow for easy expansion:

- Text content is organized by reading level in `/data/content/text/`
- Modules are organized in `/scenes/modules/` with associated scripts in `/scripts/modules/`
- Core systems (data management, audio, progress tracking) are in `/scripts/core/`
